# WoW Forever Class Abilities

Single-file page (`index.html`): every trainable and talent ability for the nine WoW: Forever classes, grouped by role, with a keybind planner (right/left-handed profiles, stance/form bars, custom loadouts) that exports a string for the **ForeverLoadout** addon.

Generated from Wowhead's Forever database (beta build 1.60.1). The source data and build scripts live in the `Wow Addons/ForeverAbilities` dev folder.

Deployed on Railway from this folder (nginx, see `Dockerfile`).
